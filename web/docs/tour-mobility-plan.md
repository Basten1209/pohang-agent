# 관광 사진 공유와 구간별 이동

2026-10-11. 사용자 승인: **수단별 시연 추정시간을 일정에 반영하고, 실제 시간은 지도·카카오T에서 확인**.

## 확인한 원인과 범위

- 기존 `localTransport`는 선택만 저장했으며 플래너는 읽지 않았다. 택시를 선택해도 구룡포행 90분·포항역 복귀 120분의 버스 시연 시간표가 유지됐다.
- 시간표와 이동 구간 목록이 분리돼 있었고, 정류장 접근 일부는 시간표 밖에서 더했다. 장소 사이 이동은 누락되거나 `transferMin`으로만 표현됐다.
- 완주 게시물은 여정당 한 장으로 제한되어 관광 사진을 추가할 수 없었다.
- 사용자 요청에 따라 실제 경로 API를 새로 연결하지 않고 수단별 **시연 추정 모델**을 분리한다. 실시간 E-UM 값은 이동시간 API가 아니며 구룡포 경유 도로의 여유 정책에만 사용한다.

## 구현

아래 수단 우선순위·혼잡 임계값·야외 제한은 규칙 기반 시연·장애 대체 모델에 적용한다. OpenAI는 같은 이동시간 자료와 사용자 요청·관측 근거로 장소와 이동수단·교통 여유를 직접 제안하고 코드 검증을 거친다. 현재 AI 계약은 [README](../README.md#agent-흐름)를 참고한다.

1. 관광 권역 도착 후 현재 관광 중인 첫 장소와 사용자가 방문 완료를 확인한 장소가 사진 공유 대상이 된다. 사진 게시만으로 방문 완료를 기록하지 않는다. 관광 탭과 채팅에서 다음 행동을 제공하며 GPS 방문 인증을 주장하지 않는다.
2. LOCAL 단계, 컨디션 OK/TIRED, 거점 도착 목표 대비 여유 20분 이상일 때 최근 방문지 사진을 제안한다. 이미 공유하거나 해당 세션에서 미룬 장소는 제안을 숨긴다. 이동·귀가·안전 단계에서는 자동 제안하지 않는다.
3. 장소명·사진·한마디·공개 범위를 확인하고 **사진 공유하기**를 눌러야 게시한다. 나중에/닫기는 게시하지 않는다. 수동 공유는 관광 탭의 다녀온 곳에서 다시 할 수 있다.
4. 완주 게시물은 `community_posts`에 유지한다. 새 `community_visit_posts`에 `(trip_id, place_id)` 고유 인덱스를 두어 장소별 한 장·동시 재시도 중복 방지를 제공한다. 기존 데이터·고유 제약 삭제 없이 추가하는 변경이다. 방문 여부와 권역은 서버 여정·카탈로그로 검증한다.
5. 같은 사진 폼을 완주/방문에 재사용한다. JPG/PNG/WebP 5MB 이하를 최대 1200px JPEG로 재인코딩하고 EXIF를 제거한다. 공개 목록에서 여정 ID·원본 바이트는 제외한다. 장소 예시 사진은 직접 촬영한 방문 사진이 아님을 명시한다.
6. `장소 → 이동 카드 → 장소` 순서로 타임라인을 구성한다. 버스/택시/도보, 출발·도착 시각, 승차·대기·도보·혼잡 여유, 추천 이유, 실제 경로 링크를 표시한다. 구간 선택과 자동 추천 복원도 제공한다.
7. 자동 추천은 피로·걷기 제한이 있으면 택시를 먼저, 그 외에는 버스를 먼저 평가한다. 같은 관광 구성에서 복귀만 택시 등 조합을 시도하고 모든 조합이 목표·걷기 한도를 넘으면 코스를 단축한다. 예산 최적화나 실제 배차를 보장하지 않는다.
8. 근거리 도보는 대표 좌표 간 거리 × 1.25 / 70m·분, 최소 3분의 시연 추정이다. 긴 도보 구간에는 택시 대안을 검토한다. 구룡포의 혼잡 여유는 택시에도 더하므로 혼잡만으로 택시가 빠르다고 판단하지 않는다. 계단 회피·야외 제한은 종전 규칙을 유지한다.
9. 탭·채팅·이전 화면·비교 도구·프롬프트가 동일한 플래너 결과를 사용한다. 기존 모델의 변경 미리보기·승인·revision 검사, 안전 우선, 중복 휴식 방지를 유지한다. 수단 버튼은 명시적인 사용자 변경이다.

## 이동시간의 근거와 한계

[포항시 구룡포읍 찾아오시는 길](https://pohang.go.kr/gu/contents.do?mid=0501010105)은 영일대 경유 900번과 포항역에서 구룡포 방면 9000번을 안내한다. 따라서 모든 구간에 환승이 필수라는 기존 문구를 제거했다. 이 페이지의 배차 간격을 전체 주행시간으로 쓰지 않았다. 실제 노선·운행은 [포항시 버스정보](https://bis.pohang.go.kr/bis/routeSearch.do) 및 지도에서 재확인한다.

아래 숫자는 공식 페이지나 E-UM이 제공한 ETA가 **아니다**. 실제 경로 시간이 확보되지 않아 사용자 승인 범위에서 분리한 시연 모델이다. 요금·실제 배차 대기시간은 연결하지 않았다.

| 대표 구간                 | 버스 승차+대기+도보 | 택시 승차+대기+도보 |
| ------------------------- | ------------------- | ------------------- |
| 영일대 출발 → 구룡포 권역 | 65+10+5 = 80분      | 40+5+2 = 47분       |
| 구룡포 → 포항역           | 70+20+5 = 95분      | 45+5+2 = 52분       |
| 구룡포 → 버스터미널       | 50+20+5 = 75분      | 35+5+2 = 42분       |
| 구룡포 → 공항             | 25+20+5 = 50분      | 20+5+2 = 27분       |
| 영일대 → 호미곶           | 75+20+5 = 100분     | 55+5+2 = 62분       |
| 호미곶 → 포항역           | 85+20+5 = 110분     | 60+5+2 = 67분       |

해당 구룡포 도로 구간에 혼잡 50 이상 +5분, 75 이상/최신값 확인 불가 +10분을 추가한다. 호미곶 직접 택시에는 구룡포 관측을 적용하지 않는다. 가까운 관광지는 버스 노선을 임의로 만들지 않고 도보 또는 근거리 택시로 연결한다. 모든 합계는 한 번만 더하며, ETA는 최종 이동 카드 종료 시각과 동일하다.

## 검증

- 별도 이동시간, 구간 선택, 버스/택시 혼합, 혼잡에 따른 근거리 선택, 시간표 연속성, 보행 한도, 진행 보고 후 중복 이동 방지 테스트.
- 방문 전/다른 권역/비활성 장소 공유 거부, 완주 사진과 동시 보존, 장소별 업로드, 동시 재시도, 부트스트랩 재실행, 공개 응답 정보 최소화 테스트.
- 의료·승인·중복 휴식·오래된 관측·실내 우선 등 기존 회귀 테스트를 함께 실행한다. 이전 버스 고정 시간에 의존한 테스트 수치는 새 시연 모델에 맞춰 갱신한다.
- 타입검사·전체 테스트·빌드 후 기존 무료 데모에 배포한다. Chrome 접근 가능 범위에서 화면 검증을 시도하고 실제 수행 범위와 증거를 `.context/`에 기록한다.
