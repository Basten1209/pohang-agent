# RUN2 데모 QA 반영

- 네비게이션: Base UI Navigation Menu + TanStack 링크. `?tab=home|race|tour|community`를 주소에 보존하며 레이스 컴포넌트는 메뉴 이동 중에도 유지한다.
- 방문 기록: `TripState.visits`는 기본값 `[]`. `visit.completed`가 당시 장소·코스·시각을 저장한다. 기존 `plan.completed`만 있는 여정은 시간 기록 없음으로 표시한다.
- 사진: `photoEligiblePlaces`를 UI와 서버에서 공유한다. 현재 관광 중인 첫 장소와 완료 장소는 허용하고 이동 중·미래 장소는 제외한다. 사진 게시와 방문 완료는 별개다.
- `POST /api/community/caption`: 저장된 여정과 장소를 검증하고 사진을 모델에 전달해 300자 이하 초안을 생성한다. 사진은 채팅 기록에 저장하지 않는다. 초안 실패 시 수동 작성/재시도를 제공하며 늦은 초안이 사용자 편집을 덮어쓰지 않는다.
- 레이스: OpenStreetMap 보행 경로를 5,000m까지 자르고 되돌아오는 10km 시연 경로. 거리와 위치는 같은 데이터에서 계산한다. 공식 대회 코스는 아니다.
- SW 캐시: `run2-v14`.

## 데이터 반영

`server/db/demo-qa.ts`는 런타임 DB 연결로 한 번 실행되는 트랜잭션이다. `app_config`의 `demo-qa-2026-10-12` 마커와 advisory lock으로 재실행·동시 실행을 방지한다. 12개의 고정 UUID 게시물을 추가하고 빈 장소 사진 및 `agent.maxOutputTokens`만 갱신한다. 전체 seed 버전은 7로 유지한다. 기존 게시물은 수정하지 않는다. 마커의 `previous`에는 기존 게시물 ID와 변경 전 설정을 보관한다.

별도 DB 접근이 가능하면 `npm run seed:community`로 사전 확인하고 `npm run seed:community -- --apply`로 동일한 고정 ID 시드를 적용할 수 있다. 이는 수동 복구/재적용용이며 기존 시드 게시물의 글·사진은 갱신한다.

## 이미지

`public/images/demo/`의 20장 모두 OpenAI 이미지 생성 도구로 만든 시연 사진을 WebP로 변환했다. 실제 방문·참가 인증 자료가 아니며 커뮤니티에 AI 시연 표시를 유지한다.

- `sample-{placeId}.webp`: food, street, gp-museum, cafe, hm-food, hm-hand, hm-museum, hm-cafe. 관광지 사진 업로드 시연용 8장.
- `community-finish-{1..3}.webp`: 바닷가 마라톤 완주 장면.
- `community-food-{1..3}.webp`: 지역 음식·해산물 식사 장면.
- `community-gp-{1..3}.webp`: 구룡포 항구·골목·카페.
- `community-hm-{1..3}.webp`: 호미곶 해맞이·여행·등대.

관광 썸네일은 기존 라이선스 사진을 우선하며 없는 경우 샘플을 사용한다. 로딩 실패에도 로컬 대체 사진을 표시한다. 기존 사진 라이선스는 `/asset-credits.html`에 유지한다.

## 추가 QA: 실제 장소 후보와 진행 안내

- `core/seed/venues.ts`에 공식 자료 기반 후보 18곳을 정리했다. 구룡포 12곳, 호미곶 6곳이며 음식·카페·볼거리, 메뉴, 주소, 원문 출처, 별도 이동 여부를 함께 저장한다. 포항 10미는 음식 분류로만 표시한다.
- 관광 탭 및 채팅 코스 카드의 `CourseCandidates`가 같은 목록을 표시한다. 일정에는 실제 식당·카페 지도 링크도 표시한다. 후보는 자동으로 일정에 추가되지 않는다.
- `plan_course`, `search_guide`, `find_nearby`가 같은 후보를 AI에 제공한다. 실시간 관광 API를 사용할 수 없는 경우에도 공식 자료의 후보를 구분해서 제공한다.
- 후보 DB 보강은 `official-venue-candidates-2026-10-12` 표시로 한 번만 실행한다. 장소의 `attrs.candidates`만 추가하며 기존 운영자 후보·좌표·시간·이미지·설정은 보존한다. 전체 시드 버전은 올리지 않는다.
- 카드를 답하지 않고 채팅한 경우의 `{ skipped: true }`는 모델 경계에서 `cardDismissed / tripChanged: false`로 변환한다. 과거 대화도 동일하게 변환한다. 실제 `SKIP` 이벤트와 구별한다.
- 진행 버튼 응답은 처리 전 장소명과 처리 후 일정으로 앱이 직접 작성한다. 다음 카페를 이전 건너뛰기의 대상으로 오해하지 않으며 모델을 재호출하지 않는다. 자유 대화에는 현재 첫 장소와 제외 목록을 명시한다.
- 사진 게시 중 문구: `포항에서의 추억을 남기는 중...`. 사진 조회 중 문구는 별도로 유지한다.
- 검증: 수정 전 실패한 회귀 2개 포함 총 239개 테스트, 타입 검사, 빌드 통과. 실제 모델로 카페 순서·시간 확인·근처 맛집 질의 확인. 360/390/768/1440px 넘침 및 이미지 실패 없음.

자료: [포항시 10미 소개](https://blog.naver.com/inpohang/223464918169), [포항시 퐝퐝여행](https://pohang.go.kr/phtour/index.do), [경북 동해안 해양관광](https://oceang.kr/). 개별 원문은 각 후보의 `source.url`에 보관한다. 당일 영업 여부는 보증하지 않는다.

### 추가 QA: 지도·장소 최신화·글자 크기 (2026-10-12)

- 추천 후보 18곳을 관광 안내와 현재 카카오맵 등록정보로 재확인. 영업 중이라고 보증하지 않으며, 자료 확인일과 당일 영업 확인 안내를 표시한다.
- 모든 후보에 장소 ID 또는 시청 안내 좌표를 지정. 할매식당은 구룡포 호미로 241의 장소 ID 9570020, 음식거리는 시청 좌표 35.9903122, 129.555267로 연결한다. 기존 이름+전체주소 검색은 제거했다.
- oceang 출처 3개를 한국관광공사/지도 매장 정보로 교체. 과거 채팅의 해당 링크도 렌더링할 때 새 출처로 연결한다.
- 커피311 주소를 현재 지도 등록 주소(호미로 311)로, 네스트코퍼레이션 명칭을 네스트카페로 갱신. 디폴트커피바는 같은 주소의 현행 지도 등록과 영업시간을 확인해 유지했다(폐업으로 단정하지 않음).
- 현재 식당 등록을 확인하지 못한 촬영지 진수백반은 제외하고, 현행 메뉴·주소가 등록된 해맞이광장 인근 대보리286식당으로 교체했다. 오핑의 상세 주소와 월·화 휴무 안내를 추가했다.
- `venue-links-verified-2026-10-12-v2`는 후보의 기존 기본값만 갱신한다. 운영자 수정, 일정, 게시물, 시드 버전은 보존한다. 이전 기본값 스냅샷을 유지해 재실행과 운영자 데이터 보존을 검증한다.
- 화면 설정에서 기본/크게/아주 크게(100/112.5/125%) 선택. 기기 저장, 첫 화면 복원, 키보드 조작, 저장소 차단 시 현재 화면 적용을 지원한다. 온보딩과 상단에 작은 설정 버튼을 둔다.
- Streamdown 외부 링크 팝업이 Radix 채팅 시트 밖의 비활성 portal에 표시되어 클릭되지 않던 문제를 중첩 Radix Dialog로 수정. 한국어 닫기·복사·열기를 각각 처리하며 복사 실패도 안내한다.
