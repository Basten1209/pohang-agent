# RUN2구룡포 발표 경험 개선 계획

작성: 2026-10-11. 발표: 2026-10-13 17:00 KST.
목표: 피드백 6종 구현 → 테스트·빌드 → 기존 무료 데모 재배포 → 모바일·데스크톱 및 설치 가능한 실행 흐름 검증.

## 구현 순서와 완료 조건

1. **브랜드·발표 메시지**
   - 앱명 RUN2구룡포 유지. 발표 대본에 “E-UM 데이터가 구룡포 기준이라 구룡포로 시작했고, 포항 전역 러닝 대회로 확장 가능하다”를 반영.
   - 현재 관측 범위는 구룡포의 검증된 장비·도로 구간으로 한정. 포항 전역 제공은 확장 방향이며 현재 지원으로 안내하지 않음.
   - PRESENTATION.md의 공공데이터 미연결 등 오래된 설명 갱신.
2. **첨부 자산·PWA**
   - 제공된 180/192/512px 앱 아이콘 적용, favicon·apple-touch-icon·manifest·테마색 통일.
   - 원본 그림을 OS 안전영역 조건을 확인하지 않은 채 maskable로 선언하지 않음. 기존 다른 캐릭터의 maskable 아이콘 제거.
   - 홈 화면 설치 안내(지원 브라우저 설치 버튼, iOS 안내), 설치 후 standalone·safe area·재실행 검증.
   - service worker 버전 갱신, API는 network-only 유지. 오프라인에서 관측·채팅·공유 성공을 가장하지 않음.
3. **한 단계씩 첫 입력**
   - 대회 선택 → 이름 확인 → 귀가 수단·시각 → 여행 취향/출발 장소 → 기존 서버 이벤트로 저장.
   - 이전 단계로 돌아가도 입력 유지, 최종 저장만 여정 생성 완료. 재방문자는 기존 여정 유지.
   - 기존 일정 수정 폼과 대화의 슬롯/상태 계약 유지. 이름은 닉네임이며 본인인증으로 표현하지 않음.
   - 사용자 확정: 현재 가상 대회 1종 선택, 영일대 출발 유지.
4. **지역 UI·캐릭터**
   - 포항시 공식 홈페이지의 파란색 강조·한글 제목 위계를 참고. 네이비 #102A43, 청록, 파란색, 흰 카드로 본문/행동/관측 근거 구분.
   - 한국어 가독성, 버튼 대비, 큰 터치 영역, 모바일 줄바꿈, reduced-motion 확인.
   - 첨부 아이콘/갈매기 포즈를 시작·로딩·챗봇·완주 화면에 일관되게 사용. 사진 출처 유지, 사용자 제공 자체 캐릭터로 표기.
5. **레이스 시연 흐름**
   - 준비(0km) → ‘마라톤 시작하기’ → 경과시간·거리·페이스·구간 위치 시연 → 완주 → 기존 축하·사진 공유·여행 체크인.
   - 시작 전 자동 진행 중지. 시연 속도/진행 조작 제공, 새로고침·탭 전환 시 같은 여정의 진행 유지.
   - 시연 기록은 실제 GPS/기록칩과 분리하고 화면 상단에 명시. 실제 위치 권한을 요구하지 않음.
   - 완주 시연과 관광 일정 시계는 별도. 기존 10:40 기준+휴식60분=11:40 계산 및 중복 휴식 방지 유지.
6. **검증·배포**
   - 레이스 시작/진행/일시정지 또는 재개/완주와 저장 복원 등 새 상태 로직의 의미 있는 회귀 테스트.
   - 기존 196개 테스트와 타입검사, production build.
   - 모바일320/390px와 데스크톱에서 온보딩 이전/다음, 설치 안내, 레이스 전환, 완주 공유, 여행 체크인, E-UM 근거 확인.
   - API/비밀정보 캐시 금지·아이콘 MIME/크기/manifest·safe-area 확인.
   - 기존 run2-pohang-demo.vercel.app에 배포, 실제 웹 검증 및 .context/에 스크린샷/검증 기록.
   - 실제 휴대폰 OS 설치는 접근 가능한 기기에서만 완료로 보고. 접속할 수 없는 기기의 검증은 구분하고 설치 절차 제공.

## 충돌과 판단

- 과거 docs/agent-ux.md의 ‘대화가 앱’, 흑백 규칙은 현재 탭 앱 및 사용자 승인된 브랜드 방향과 이미 다름. 이번 입력 마법사는 같은 서버 슬롯 이벤트를 사용해 기존 에이전트 계약 유지.
- 서버 PRE_RACE/CHECK_IN 등 여행 상태와 레이스의 로컬 시연 시계를 분리. 완주 전 안전/체크인 우회, 자동 사진 공개, 실제 측정으로 오인하는 표현 금지.
- 사용자 확인된 현재 대회는 영일대 출발 가상 대회 1종. 구룡포는 완주 후 추천 권역이며 사용자 답변 없이 장소/날짜/경로를 임의 변경하지 않음.
- 18:30 열차는 사용자 입력 귀가 조건이며 실시간 열차 조회에서 확정된 편으로 표현하지 않음.
- Vercel Hobby/Neon Free 유지, 초대·결제 설정 변경 없음.
