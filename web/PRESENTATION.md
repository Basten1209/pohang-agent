# 2026-10-13 발표용 데모

대회는 **2026-10-13 08:30**의 가상 해변런이고, 발표는 **같은 날 17:00 KST**다. 완주 후 여행은 기본 10:40부터 재현한다. E-UM의 관측 시각과 조회 시각은 실제 시간이며 가상 일정으로 바꾸지 않는다.

## 연결 상태

- 데모: https://run2-pohang-demo.vercel.app
- Vercel: `basten1209s-projects/run2-pohang-demo`, Root Directory `web`, Build Command `npm run build`.
- Neon Free: 전용 `run2-pohang-demo`, Singapore. Production에 연결하고 Preview에는 배포별 DB 분기 옵션을 사용한다. 기존 다른 DB를 공유하지 않는다.
- E-UM: postech09 계정의 기존 키 사용. 키 원문은 서버 환경변수에만 저장한다.
- OpenAI: 새 데모 서버 환경변수 연결. 공공데이터포털: 관광정보·기상예보·버스정류소·버스도착·버스노선·열차정보 6종 승인 및 서버 키 연결 완료(2026-10-11). 키가 없거나 AI 호출에 실패하면 규칙 기반 응답 / 미설정 안내. 환경변수 존재 여부는 `/api/status`, 실제 E-UM 응답은 `/api/evidence`에서 구분해서 확인한다.

## 실제 응답을 통해 확인한 계약

2026-10-11 네 가지 API 모두 HTTP 200을 확인했다.

| API         | 해석                                                                                                                                                                      | 추천 반영                                                      |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| INT_S07_005 | `hour` KST, `cntPerc` %. **100% 초과도 실제 응답**에 존재                                                                                                                 | 관측 후 2시간 이내, 구룡포 경유가 확인된 도로 구간             |
| INT_S01_004 | `logDateTime`, 장비 ID 지정, `pm25`, `pm10`, 기온·습도                                                                                                                    | 문서의 PPM 단위가 불명확해 표시만 함                           |
| INT_S01_012 | 실제 서버는 `date=YYYY-MM-DD` 요구. 문서의 YYYYMMDD 예시와 다름. `hours`에 요청 날짜를 결합하고 미래·집계 중인 시간대의 0 채움 행을 제외, `devId`·PM25 필터, `㎍/㎥` 확인 | 장비 8(구룡포 수협 위판장 인근), 2시간 이내 관측               |
| INT_S06_005 | `dateTime` KST, `uvIndex`                                                                                                                                                 | 구룡포, 관측 후 2시간 이내. 6 이상 햇빛 주의, 8 이상 실내 우선 |

장비 위치 확인을 위해 `INT_S01_001`을 추가 신청했다. 위판장 인근 장비 8(35.990694, 129.555917)의 위치와 두 대기 API 응답을 대조했다. 이 장비의 시간 통계를 시장·가옥거리 주변의 참고 관측으로 사용하며, 포항이나 구룡포 전체를 대표한다고 표시하지 않는다. `EUM_AIR_DEVICE_ID=8`과 `EUM_AIR_VERIFIED=true`가 함께 있어야 판단에 반영한다. 다른 장비는 다시 검증해야 한다. 최신 교통 응답이 있어도 오래된 대기값을 유효하게 만들지 않는다. 실패·과거 스냅샷·시연값을 구분하며 실패를 0이나 쾌적으로 바꾸지 않는다.

## 추천 정책

- 교통 혼잡률 50 미만: 구간 여유 0분, 50 이상: 5분, 75 이상 또는 확인 불가: 10분.
- 구룡포 왕복 도로 구간에 각각 적용한다. 호미곶은 구룡포 경유가 명시된 출발 버스 구간만 적용하고, 직접 택시에는 적용하지 않는다. 다른 권역인, 영일대·죽도에는 적용하지 않는다. 도보에는 교통 여유를 붙이지 않는다.
- 시간표의 구간 종료·장소 도착·귀가 ETA·여유 시간은 같은 계산을 사용한다. 마지막에 교통 여유를 다시 더하지 않는다.
- 피로 또는 걷기 한도 15분 이하이면 택시 제안, 귀가 여유 20분 미만이면 귀가 확인 우선. 나머지는 대중교통 제안. 혼잡은 두 수단 모두에 영향을 준다.
- 수단 선택은 저장되지만 택시 시간·요금·배차를 생성하지 않는다. 실제 이동은 지도/카카오T에서 확인한다.
- 확인된 대기값 PM2.5 36 이상 또는 UV 8 이상이면 실내를 우선한다. 대기 미확인은 좋음으로 판단하지 않는다. 이는 앱의 관광 조정 정책이며 의료 판단이 아니다.

## iPhone Chrome → 홈 화면 → Mac 미러링

1. iPhone **Chrome**에서 https://run2-pohang-demo.vercel.app 접속.
2. 주소창 **공유 → 홈 화면에 추가 → 추가**. 갈매기 아이콘과 RUN2구룡포 이름 확인.
3. 홈 화면 아이콘으로 실행. 주소창 없는 앱 화면에서 처음 한 번 일정 입력. Chrome 탭과 설치 앱의 저장 영역이 다를 수 있으니 **설치한 앱에서 리허설**한다.
4. Mac의 iPhone 미러링 또는 이미 사용하는 화면 미러링으로 기기 화면 표시. 실제 iPhone을 연결해야 설치·재실행까지 검증할 수 있다.
5. 발표 전에 한 번 앱을 열어 캐릭터·폰트를 불러 둔다. 인터넷은 유지한다. 오프라인은 마지막 일정 확인만 가능하며 추천·관측·공유는 온라인 기능이다.

앱의 `홈 화면에 추가` 버튼에도 같은 기기별 안내를 제공한다. [Chrome 공식 안내](https://support.google.com/chrome/answer/9658361?co=GENIE.Platform%3DiOS&hl=ko).

## 시연 순서 (약 3분)

1. iPhone 홈 화면의 갈매기 아이콘 → RUN2구룡포 스플래시.
2. **대회 선택 → 이름 확인 → 귀가 일정(18:30 열차) → 여행 취향(구룡포)**. 대회는 2026 포항 영일만 해변런 1종이며 발표용 가상 대회임을 표시한다.
3. 홈 → **레이스 준비하기 → 마라톤 시작하기**. 0km부터 지도 위 경로·현재 위치·거리·시간이 함께 진행된다. 내 평균 페이스와 총 예상 완주시간을 확인한다. 순위·다른 참가자·상위 비율은 제공하지 않는다. **발표용 시연 조작**을 열어 **60×** 또는 **마지막 1km로 이동 · 시연**으로 단축한다. 일시정지·재개 가능, 같은 여정의 시연은 탭 이동·새로고침 후 이어진다.
4. **마라톤 완주! 구룡포 여행으로 떠나요** → 완주 축하·갈매기 → 시연 사진 사용 → 사진 공유하기. 공유는 버튼을 눌렀을 때만 공개된다.
5. 커뮤니티에서 사진 확인 → 여행 준비 → **1시간 쉬고(11:40) → 조금 지쳤어요**. 레이스 시연 경과 시간은 여행 출발 시각을 바꾸지 않는다.
6. 관광 탭의 장소 사이 이동 카드에서 버스·택시·도보와 승차/대기/도보/혼잡 여유를 확인한다. 수단을 바꾸면 명시된 시연 추정으로 시간표가 재계산된다. 실제 시간은 지도·카카오T에서 확인한다.
   - 이 코스로 출발 → 구룡포 도착 → 장소 다 봤어요 → 여행 친구의 사진 제안 → 업로드 또는 장소 예시 사진 → 공개 내용 확인 후 사진 공유하기 → 커뮤니티의 장소명 확인. 촬영·공유를 건너뛰어도 일정은 계속된다.
   - 컨디션 괜찮아요·10:40 출발·16:00 열차 조건은 출발 버스/복귀 택시 조합 시연에 적합하다. 기본은 18:30 조건이며, 사진 제안은 도착 목표 대비 20분 이상 여유가 있을 때 나온다.
7. 시간이 있으면 귀가시각 변경 → 미리보기 → 승인/유지 또는 발표 모드의 혼잡 시연으로 설명한다. 시연 조건은 실제 관측과 별도 표시한다.
8. 다시 처음부터 리허설하려면 메뉴 `새 여정 시작`. 기존 여정은 서버에 보존되며 새 여정의 레이스는 0km부터 시작한다.

## 실제 데이터의 제한

- 2026-10-11 확인: 기상청 10/13 구룡포 24시간 예보가 Neon에 저장됐으며 원 발표 시각(10/11 20:00 KST)을 보존한다.
- TAGO 열차는 10/11 포항→서울 17편, 10/13은 정상 응답이지만 0건이었다. 운행이 없다는 뜻으로 말하지 말고 코레일톡/SRT에서 확인하도록 안내한다. 입력한 18:30은 사용자 귀가 조건이다.
- 관광 검색·상세와 구룡포 정류소/노선/도착 정보는 실제 연결됐다. 왕복 이동 소요시간은 계속 명시된 시연값이며 실시간 경로·택시 시간/요금 API를 연결한 것은 아니다.

## 운영 설정과 검증

`web/.env.example`의 키를 Vercel 서버 환경변수에 설정한 뒤 재배포한다. `VITE_` 접두사를 사용하지 않는다. `AGENT_APPROVAL_SECRET`은 환경별로 안정된 임의 문자열을 사용한다. 기상청 예보는 요청한 날짜만 반환하고, DB에 저장된 오전 예보는 원래 발표 시각을 보존해 오후 발표에도 저장 예보로 표시한다. 사전 조회가 없으면 과거 오전 예보를 만들어 내지 않는다.

```sh
cd web
npm ci
npm run check
npm run build
```

자산 출처와 사용 허가는 `/asset-credits.html`에 표기했다. 캐릭터는 프로젝트 소유자가 제공한 갈매기 디자인이며 포항시 공식 마스코트가 아니다. 시 공식 캐릭터의 별도 사용 승인·변형 제한 때문에 승인된 대체안으로 구현했다.

## RUN2구룡포 완주 공유 업데이트

- 앱 이름은 RUN2구룡포, 활성 관광 코스는 구룡포·호미곶이다. 영일대/죽도 관광 선택지는 비활성화했다. 기존 여정의 장소 정보를 읽을 수 있도록 카탈로그는 남겼다.
- 완주 버튼은 축하 화면을 먼저 연다. 사진 선택 또는 AI 시연 사진 → 한마디 → 명시적인 공유 버튼 → 커뮤니티 저장 → 여행 준비 순서. 사진 없이 진행도 가능하다.
- JPG/PNG/WebP 5MB 이하 입력을 브라우저에서 최대 1200px JPEG로 변환한다. 서버는 1MB 이하 data URL만 받고, Neon `community_posts`에 저장한다. 여정당 한 게시물, 중복 요청은 기존 게시물을 반환한다. 공개 목록은 사진 원본·여정 UUID를 포함하지 않는다.
- 시연 사진은 가상 러너이며 AI 생성 표기를 붙인다. 생성 방식과 최종 프롬프트: [docs/finisher-image-prompt.md](docs/finisher-image-prompt.md).
- 코스 카드/관광 시간표/에이전트 도구 응답에는 장소명·권역을 함께 표시한다. 식당·카페 미선정 장소는 후보 권역으로 명시한다.
- 출발시간 초과 오류: 기본 10:40 + 60분 = 11:40은 계산 가능하다. 체크인 후 첫 `plan_course`에서 AI가 `extraRestMin:60`을 다시 보내면 12:40이 되어 시연 경로 출발 범위 10:00–12:00을 벗어나는 결함을 재현했다. 최초 계산은 저장된 체크인 정보를 그대로 사용하도록 제한했으며, 이후 사용자가 요청한 추가 휴식 변경은 유지한다. 시연 시간 범위 초과와 경로 누락은 별도 안내한다. 당시 사용자 대화 원본을 확보하지 못했으므로 해당 사례의 정확한 호출 내역까지 확정한 것은 아니다.

## 레이스 지도

영일대 주변의 예시 좌표를 10km 시연 진행률에 맞춰 보간한다. 실제 GPS나 공식 코스를 재현하지 않으며 기기 위치 권한을 요청하지 않는다. 지도 배경은 [OpenStreetMap 타일 정책](https://operations.osmfoundation.org/policies/tiles/)에 따라 현재 화면에 보이는 타일만 로드하고 출처를 표시한다. 서비스 워커는 외부 지도 타일을 캐시하거나 미리 내려받지 않는다. 네트워크 오류 시 지도 안내를 표시하며 로컬 시연 기록은 유지한다.

## 포즈별 갈매기 사용

인사·생각·지도·축하 포즈는 독립된 투명 PNG로 사용한다. 홈은 완주 전 지도/완주 후 축하, 관광은 지도 또는 생각, 커뮤니티와 완주 시트는 축하, 채팅 시작은 인사/답변 준비는 생각 포즈를 표시한다. CSS로 4포즈 원본을 잘라 쓰던 방식을 제거했다. [원본·최종 생성 프롬프트](docs/gull-pose-cutout-prompts.md).

## 관광 사진·구간별 이동 업데이트

상세 정책과 시간 근거는 [docs/tour-mobility-plan.md](docs/tour-mobility-plan.md). 완주 게시물은 기존 테이블에 보존하고 방문 사진은 `community_visit_posts`에 여정·장소별 한 장씩 별도로 저장한다. 사용자 방문 확인 기반이며 GPS 인증 기능이 아니다. 장소 예시 사진을 사용한 글에는 직접 촬영한 사진이 아니라는 표기를 붙인다.
