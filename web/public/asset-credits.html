Wikimedia Commons의 축소본을 사용하며 화면 비율에 맞춰 잘려 보일 수 있습니다. CC BY-SA 사진의 파생물에도 원본과 같은 라이선스를 적용합니다. 사진은 촬영 당시의 지역 풍경이며 현재 현장이나 가상 대회 개최를 증명하지 않습니다. 저작자는 이 서비스를 후원하지 않습니다.

갈매기 아이콘과 4가지 포즈는 2026-10-11 프로젝트 소유자가 제공한 RUN2구룡포 캐릭터 디자인입니다. 인사·생각·지도·축하 갈매기는 제공된 원본을 바탕으로 OpenAI 이미지 도구로 포즈별 배경을 제거한 독립 투명 이미지입니다. 시작·첫 입력·홈·관광·채팅·완주·커뮤니티 화면에서 이미지 전체가 보이도록 표시하며, 여러 포즈가 붙은 원본을 잘라 쓰지 않습니다. 생성 프롬프트는 저장소 docs/gull-pose-cutout-prompts.md에 기록했습니다. 앱 아이콘 생성 프롬프트는 저장소 docs/app-icon-prompt.txt에 기록했습니다. RUN2구룡포는 발표용 가상 대회 여행 서비스이며 포항시 공식 앱이 아닙니다.

완주 시연 사진(finisher-demo.png)은 OpenAI 이미지 생성 도구로 제작한 가상 성인 러너입니다. 실제 참가자나 실제 대회 현장을 촬영한 사진이 아닙니다.

한국어 본문은 Noto Sans KR(자체 호스팅, SIL Open Font License 1.1), 영문은 Geist를 사용합니다. 포항시 홈페이지의 파란색 강조와 제목 위계를 참고했으며 시의 폰트·로고를 복제하지 않았습니다.

레이스 배경 지도: © OpenStreetMap contributors. 이동 선은 routing.openstreetmap.de의 OpenStreetMap 보행 경로(ODbL)를 5km 반환·10km 왕복으로 구성한 시연 데이터입니다. 실제 GPS 기록이나 공식 대회 코스가 아닙니다.
