# RUN2구룡포 구조 교정 계획 및 변경 비교표

이 파일은 이전 교정 단계의 기록이다. 최신 줄글·Humanizer·목적 보강은 [줄글 교정 및 목적 검토](줄글-교정-및-목적-검토.md), 최초 원문부터의 누적 변경은 [전체 수정 전후 비교표](수정-전후-비교표.md)를 기준으로 확인한다.

비교 기준: 이번 구조 교정 직전의 15쪽 완성본. 문장 Humanizer를 다시 적용하지 않고, 장별 역할·들여쓰기·그에 따른 표현 관점과 중복을 정리했다.

## 실행 계획

| 장 | 집중할 역할 | 실행 내용 |
|---|---|---|
| 1. 발상 동기 | 필요성 | 배경·이동 문제·기존 도구 한계·완주자 질문·우선 대상 유지. 구현·검증·효과 측정은 해당 장으로 이동 |
| 2. 서비스 내용 | 이용 경험 | 이용 흐름·판단 개요·250분→205분 예시·차별성 유지. 요건 확인표와 가산 규칙은 3장으로 이동 |
| 3. 구현 방법 | 구현과 검증 | 요건 충족·연동·규칙·검증을 모으고 준비 상태를 개발 일정 바로 앞에 배치. 데모 등록은 MVP 포함의 하위로 이동 |
| 4. 기대효과 | 효과와 활용 | 완주자 항목을 사용자 관점으로 이동. 상권·지역 행사·운영 효과를 구분하고 효과 가설·성과지표·확장 대상을 함께 배치 |
| 5. 기타 사항 | 제약과 유의사항 | 안전·개인정보·운영 제약·참고자료 유지. 준비 상태는 3장으로 이동하고 반복된 시연 목록 통합 |

## 보존 범위

5개 대단원 제목과 순서, 표 12개와 열 너비, 이미지 4개와 크기, 코드 예시, 근거 수치·출처를 유지했다. 표 번호는 새 배치 순서에 맞게 자동 갱신했다.

## 변경 내역

문구 수정 21건, 추가 1건, 삭제·통합 7건, 문구가 같은 배치 변경 17건. 장을 옮긴 블록은 17개다. 문구 수정과 배치 변경이 겹치는 항목은 한 번만 표시했다.

표의 문구는 원문 그대로 수록했다. 장·블록 번호는 각각 해당 판본 기준이며 1부터 센다. 이동으로 블록 번호만 밀린 항목은 변경으로 세지 않는다. 추가·삭제는 해당 칸에 표시했다.
