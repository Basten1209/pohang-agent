# RUN2구룡포 남은 기술 확인 사항

이번 작업은 제출 문서의 논리·문장·장별 배치와 들여쓰기 교정이다. 아래 항목은 구현이나 실험을 수행한 결과가 아니며, 문장 수정만으로 해결했다고 볼 수 없어 별도로 남긴다.

| 확인 항목 | 현재 문서에서 남은 공백 | 구현·검증 시 확인할 내용 |
|---|---|---|
| LLM 방문 순서와 시간 예산 | `stopOrder`가 `allowedPlaceIds` 안에 있는지는 검사하지만, 순서 변경 후 이동시간·운영시간·복귀 마감 재검증은 명시되지 않음 | 순서 변경으로 ETA가 늘어나는 사례를 검사하고, 최종 시간 계산을 담당할 위치와 실패 시 반환할 일정을 확정 |
| 제외 이유 질의응답 | 허용 장소 외 추천을 금지하도록 문구를 맞췄으나, 현재 LLM 입력 요약에는 제외된 장소와 제외 이유의 전달 방식이 없음 | ‘호미곶은 왜 빠졌나요’에 답할 근거를 어떻게 전달할지 확정하고, 근거가 없는 경우 추측하지 않는 응답 확인 |
| 결정 임계값과 우선순위 | `cntPerc` 하위·중위·상위 경계, 소스별 `STALE` 기준, 환경 임계값, `DELAY`·`SHORTEN`·`INDOOR`가 겹칠 때의 우선순위 미정 | 시연 설정과 실사용 설정을 구분해 수치·우선순위를 정하고 경계값 테스트. `PTY`는 강수 유형 코드, `PCP`는 강수량 범주·문자열을 포함할 수 있어 정규화 규칙도 확인 |
| 데이터 누락과 정적 이동 버퍼 | 환경 관측 누락 시 해당 값을 판단에서 제외하는 정책은 남아 있음. 정적 이동 버퍼의 적용 구간·갱신 주기는 미정 | 환경 데이터 부재를 야외 활동 가능으로 오인하지 않는지 확인. 등록 구간의 정적 시간에 회복·체류·안전 여유를 함께 합산하고, 어떤 ETA·캐시·정적 시간도 없을 때 `CANCEL` 확인 |
| 외부 API 실호출 | 명세를 바탕으로 작성한 계획이며, 이번 교정에서 실제 API 호출·키 승인·장비 검증은 수행하지 않음 | E-UM 교통·대기와 Kakao부터 키·응답·장비 위치·단위·시각을 검증. 기상청·TourAPI 응답 계약과 오류·빈 응답 처리 확인. 실제 관측의 변화와 시연용 입력 교체를 구분 |
| 사용성 평가와 지역 효과 | 러너 5명 테스트로 방문·소비 증가를 입증할 수 없음. 도착·재계산 시각으로 체류시간을 추정하는 방식에는 오차가 있음 | 계획 저장·재계산 완료·길찾기 실행의 분모와 성공 이벤트를 정하고, 실제 방문 확인과 이동 의향을 구분. 지역 효과는 별도 현장 실증에서 검증 |
| 개인정보 보존과 집계 | 건강 관련 원문 미저장·상태 코드 저장 원칙은 정리했으나 삭제 시점, 식별자 연결, 소규모 집계 처리의 세부 계약은 없음 | 저장·로그·백업에서 삭제 범위와 보존 기간을 일치시키고, 도착 확인 동의와 소규모 집계의 식별 가능성 확인 |

## 문서에 반영한 사실 교정

- 기상청 `getVilageFcst`의 강수량 필드를 `RN1`에서 `PCP`로 수정. `RN1`은 초단기예보·실황 계열과 구분해 사용해야 함. [기상청 API허브의 단기·초단기예보 설명](https://apihub.kma.go.kr/apiList.do?seqApi=10)
- 경로 정보 부재 시 취소 조건에 기존 정적 이동 버퍼를 포함하고, 자가 컨디션을 측정된 운동부하처럼 표현하던 문구를 수정.
- 사용성 검증과 지역 효과의 가설을 구분하고, 대중교통 이용 비율은 확장 후 집계 항목으로 표시.

## 제출 정보 확인

팀명·팀원·연락처·서명 등 기존 빈칸은 그대로 유지했다. 실제 적용할 행사의 코스·출발시각과 확장 항목의 버스 배차 정보는 적용 전에 원자료를 다시 확인해야 한다.

## 도입부에 추가한 근거와 해석 범위

- 러닝 참여 증가: 규칙적 체육활동 참여자가 주요 종목 1~3순위로 달리기를 응답한 비율이 2024년 4.8%에서 2025년 7.7%로 증가. 전체 국민 중 러너 비율이나 마라톤 참가자 증가율로 해석하지 않음. [문화체육관광부 조사](https://www.mcst.go.kr/site/s_policy/subPolicy/sportstour/sportstour29.jsp)
- 포항 대회: 통일기원 포항마라톤은 2026.4.24 개최 안내의 코스를, 철강마라톤은 경상북도의 2026.6.14 개최 결과를 사용. 철강마라톤의 초기 영일대 안내보다 실제 송도 개최 결과를 우선 반영. [통일기원 대회 안내 보도](https://news.tf.co.kr/read/releasecopy/2316866.htm), [경상북도 개최 결과](https://inseri.gb.go.kr/Main/saemaul/page.do?BD_CODE=bbs_bodo&B_LEVEL=0&B_NUM=508459301&B_STEP=508459300&Start=50&V_NUM=14409&bdName=&cmd=2&dept_code=&dept_name=&key=4&mnu_uid=6792&p1=0&p2=0&tbbscode1=bbs_bodo&word=)
- 과거와 현재 비교: 2022년 호미곶 광장~구룡포해수욕장 교차로 코스와 2026년 확인한 도심 해안권 대회로 비교 범위를 한정. 현재 구룡포에서 열리는 모든 러닝 행사의 존재 여부까지 전수 확인한 것은 아님. [2022년 대회 보도](https://www.pressian.com/pages/articles/2022111318233820703)
- 관광 연계: 경주와 제주 사례는 지자체·관광협회의 전략과 운영 사례이며, RUN2구룡포의 제휴나 할인 제공을 뜻하지 않음. 완주 후 피로·이동시간·복귀 마감이 구룡포 방문을 막는다는 설명은 현장 검증할 문제 가설로 표시. [경주시 안내](https://www.gyeongju.go.kr/news/page.do?mnu_uid=1342&parm_bod_uid=310262&step=258), [제주관광협회 공고](https://www.visitjeju.or.kr/visitjeju/comm/notice.htm?act=view&page=2&seq=58528)

## 최종 문장 재점검에서 명확히 한 범위

피로도가 높은 경우의 `DELAY`·`SHORTEN`·`INDOOR` 제한은 관광이 가능한 경우에 적용하며, 최소 일정도 불가능하면 `CANCEL`이라는 기존 원칙을 유지한다. 원본 건강·위치 이력의 LLM 입력 제한은 일정·설명 생성 단계의 경계이며, 앞 단계의 자연어 제약 추출과 구분했다. 이 문장 교정은 위의 결정 임계값·우선순위나 실제 입력 계약을 구현·검증했다는 의미가 아니다.

## 줄글 교정 후 확인 범위

배경·이용 장면·설계 이유·효과 측정을 문장형으로 보강했지만, 서비스 목적을 명확히 한 문구는 구현 완료나 관광 효과의 실증 결과를 뜻하지 않는다. 위 7개 기술 확인 사항은 그대로 남아 있다.
